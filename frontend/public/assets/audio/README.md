# Liberation Frequency — album samples

The store's album section (`/store#frequency`) plays a sample of each track from
this folder. Drop the audio files here with the **exact filenames** below and the
"Play sample" buttons light up automatically — each filename maps to its track name.

Format: `.mp3` (the player also accepts a browser-supported codec if you keep the name).
The player streams the first ~45 seconds as a sample.
